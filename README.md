# Cybersecurity SOC & DFIR Portfolio

A hands-on learning portfolio focused on Security Operations Center (SOC) workflows, network threat detection, digital forensics and incident response (DFIR), SIEM detection engineering, and AI-assisted security automation.

**Author:** Abdelrhman   
**Academic Background:** Computer Science  
**Focus Areas:** Cybersecurity, Network Security, SOC Analysis, Incident Response

## Projects

### 1. Network Traffic Analysis & C2/Exfiltration Detection
Analyze network traffic to identify suspicious connections, scanning activity, command-and-control indicators, DNS anomalies, and potential data exfiltration.

**Planned tools:** Wireshark, Zeek, Suricata, Python  
**Key deliverables:** Annotated PCAPs, protocol analysis, IOC lists, detection logic, and a threat analysis report.

### 2. Windows & Linux Host DFIR and Persistence Investigation
Investigate host artifacts, authentication events, processes, persistence mechanisms, and operating-system logs in controlled lab scenarios.

**Planned tools:** Windows Event Viewer, Sysmon, Autoruns, Volatility, Linux journald and authentication logs  
**Key deliverables:** Event analysis, investigation timelines, persistence findings, IOC lists, and a DFIR report.

### 3. Phishing, Malware & End-to-End Incident Response
Investigate suspicious emails and simulated security incidents, document indicators, scope affected assets, and develop containment, eradication, and recovery plans.

**Planned tools:** Email-header analyzers, safe malware-analysis labs, forensic utilities, MITRE ATT&CK  
**Key deliverables:** Incident timeline, IOC analysis, evidence log, response plan, and executive report.

### 4. SIEM Detection Engineering & SOC Operations
Build and test detection use cases, review alerts, develop dashboards, and document a repeatable SOC triage workflow.

**Planned tools:** Wazuh, Splunk or Elastic Stack, Sigma concepts, MITRE ATT&CK  
**Key deliverables:** Detection rules, alert triage reports, dashboard metrics, tuning notes, and a SOC operations report.

### 5. AI-Assisted SOC Automation & Incident Response Capstone
Explore how local language models can assist with alert summarization, investigation planning, report drafting, and response-workflow design, with human validation of every security conclusion.

**Planned tools:** Ollama or LM Studio, Python, TheHive concepts, local security logs  
**Key deliverables:** Prompt library, validation log, SOAR playbooks, incident timeline, and final capstone report.

## Methodology

Each project is organized around a defined objective, controlled lab environment, evidence collection, analysis, validation, documented findings, and actionable recommendations.

AI-generated analysis is treated as a hypothesis and verified against source evidence before inclusion in reports.

## Responsible Use

All investigations and simulations are intended for authorized systems, owned lab environments, or publicly available training datasets. No unauthorized access, exploitation, or collection of private data is intended.
